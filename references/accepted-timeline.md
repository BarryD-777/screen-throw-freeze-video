# 固定时间线：节奏、布局与换字

## 来源与范围

此时间线来自已经过实际成片检查的静帧背景版本。公开包保留逐帧归一化展开进度和对应BGM，不发布原视频、产品字稿或私人制作工程。

原片中的成分和未检出文案不作为新产品的事实来源。`assets/reveal-clock.json`只有时序和比例数据；换产品后必须重新取得对应文案。对应原音轨在`assets/reference-bgm.m4a`，另见[音乐素材说明](../assets/MEDIA-LICENSE.md)。

## 固定事件

所有帧号从0开始，使用同一个30fps时钟；时间窗口按左闭右开处理。

| 事件 | 帧 | 秒 |
|---|---:|---:|
| 大屏持物、抛出、左手快速接稳 | 0–96 | 0–3.233 |
| 图形产品接管与短促旋转模糊 | 97–100 | 3.233–3.367 |
| 背景静帧接管、左标题与第1项 | 101 | 3.367 |
| 转场暗部收稳 | 103 | 3.433 |
| 产品收稳为轻微漂浮 | 104 | 3.467 |
| 左侧第2–8项起点 | 106,111,118,124,130,135,141 | 3.533–4.700 |
| 右标题与第1页 | 158 | 5.267 |
| 第2页 | 213 | 7.100 |
| 第3页 | 270 | 9.000 |
| 第4页 | 329 | 10.967 |
| 第5页 | 388 | 12.933 |
| 第6页 | 446 | 14.867 |
| 第7页 | 504 | 16.800 |
| 第150项起点 | 533 | 17.767 |
| 结束，不包含此帧 | 563 | 18.766667 |

每行按`changes`快速展开，而非整行同时出现。每个元素为`[全局帧号, 0到1的裁切比例]`。起点前为0，变化之间保持前值，到1后保持至`hold_end_frame`（不含该结束帧）。

## 画面关系

- 16:9、1280×720、30fps，音乐原速从0秒开始。新音乐或竖屏属于明确改版，需重新检查匹配。
- 稳定产品中心约`(640,356)`，可见高度约450px；按新包装比例适配，不沿用旧轮廓。
- 产品参考摆角为`10 + 1.8*sin((f-97)*0.027)`度；104帧后上下参考位移为`7*sin((f-104)*0.049)`px。背景不跟随。
- 左文案面板约x60、y73，条目左缘约x100。右标题约x901、y53；正文约x925、y118，各页在同一区域替换。字体和长词需要按实际可见边界适配，不碰产品与光晕。
- 紫白渐变粗体、紫色立体边、黑色细描边。换文案时用真实字体重新渲染。
- 101帧背景冻结，101–103帧完成暗部转场，此后背景位置、缩放和透明度固定。

## 换字输入

在本次制作目录保存`copy.json`：

| 字段 | 规则 |
|---|---|
| `ingredients` | 最多8个成分名称，单行字符串，无编号 |
| `not_detected` | 最多150个完整陈述，单行字符串，无编号 |
| `left_title` | 可选，默认“核心成分：” |
| `right_title` | 可选，默认“未检出成分” |
| `opening_text` | 可选，默认null；仅明确要求时写入，最多两行，显示窗口0–100帧 |

检测只支持“未检出”时保留该措辞，不为了模仿旧片改为“不含”。不传入带编号的行，编号由渲染器根据`number`产生。工具不自动增加断言。

```text
python scripts/make_cues.py --copy <copy.json> --output <新目录/cues.json> --audio <本地有权使用的音轨>
```

`--audio`可省略，默认自动使用`assets/reference-bgm.m4a`；只有未指定音乐且附带文件缺失时，`audio.source_asset`才为null，`audio.requires_user_asset`为true。显式指定音轨会检查文件存在，输出本地绝对路径；错误路径会报错，不自动回退。渲染器合成前必须解析有效音轨。

空列表不显示对应标题。少项版本保留时间线并隐藏空位，不重复补齐。超出容量或出现重复/空行时工具报错。工具不会覆盖已有输出。

## 渲染器怎样使用输出

1. 从`canvas`取得帧率、分辨率和563帧总长。
2. 对每行的新文案排版，测量实际可见字形宽度；在当前全局帧查找最近的`changes`进度，取可见宽度乘进度进行裁切。
3. 从`start_frame`至`hold_end_frame`显示该行。右侧页面到结束帧后整体移除，下一页使用自己的起点。
4. 标题只在非null时按各自`title_frame`显示。片头文字为空时整段不加字，不平移后半段。
5. 音轨按`audio.start_frame=0`、`speed=1`放置。相同音乐才能保留原先的鼓点对应关系；换曲后需单独确认。

`cues.json`是给合成器的时序输入，不是成片文件，也不验证成分或检测结论。原曲结尾略短于视频时沿用实际结尾，不擅自伸长音乐或补节拍。
